# FAQ

## Is MC Linker free?

Yes. Every feature is free. The optional **Customize MC Linker** subscription lets you run MC Linker as [your own bot](../features/custom-bot.md) with your own name, avatar and status. Changing MC Linker's look [in your own server](../features/customization.md) is free.

## Do I need to host a bot or edit config files?

No. The bot is hosted for you and everything is set up with slash commands. The plugin works out of the box; its [config file](../plugin/configuration.md) is only for fine-tuning.

## Which servers and versions are supported?

Paper, Spigot and Purpur from 1.8, Fabric 1.16.5 – 26.2, NeoForge 1.21.1 – 26.2, Forge 1.16.5 – 1.20.x and hybrid servers. See [Installing the plugin](../getting-started/installing-the-plugin.md).

## Does it work with Bedrock players?

Yes, through Geyser and Floodgate. Bedrock players can [link their accounts](../features/account-linking.md) using their name with the Floodgate prefix. See [Integrations](../plugin/integrations.md#geyser-and-floodgate-bedrock-players).

## Does it work on offline-mode (cracked) servers?

Yes. Cracked players can link their accounts too, per server.

## Can I connect more than one Minecraft server?

Each Discord server links to one Minecraft server at a time. You can link several Minecraft servers to several different Discord servers.

## Does it work with BungeeCord or Velocity?

Install Discord-Linker on the backend server you want to link and set `online: True` when you `/connect`. See [Integrations](../plugin/integrations.md#proxies-bungeecord-velocity).

## Does it work on Aternos and other hosts?

Yes. On Aternos, install Discord-Linker from the plugin list. Other hosts work as long as they allow outgoing connections.

## Do I need to open a port?

No. The plugin connects out to MC Linker.

## Can I change how chat messages look in Minecraft?

Yes, with `message`, `private_message` and `reply_message` in the plugin's [config.yml](../plugin/configuration.md).

## Can I limit who uses which command?

Yes, with Discord's own command permissions: [Permissions](../getting-started/permissions.md).

## What data does MC Linker store?

See the [Privacy Policy](https://mclinker.com/privacy).

## Can I help translate MC Linker?

Yes! Translations happen on [Crowdin](https://crowdin.com/project/minecraft-smp-bot).

## Where do I report bugs or suggest features?

On the [support server](https://discord.gg/rX36kZUGNK), or on [GitHub](https://github.com/MC-Linker).
