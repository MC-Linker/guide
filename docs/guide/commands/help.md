# /help

Explains every MC Linker command right in Discord.

<CommandInfo discord="Everyone" where="Discord servers and DMs with the bot" needs="Nothing" />

## Usage

```
/help
/help command: Moderation
/help command: chatchannel
```

| Option | Required | What it does |
|---|---|---|
| `command` | No | A category (**Main**, **Moderation**, **Other**, **Settings**) or a command. Suggestions appear as you type. |

Without an option, `/help` lists the categories. With a category, it lists its commands. With a command, it shows a longer description and how to use it.
