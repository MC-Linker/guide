# Customization

Make MC Linker fit your server. Give it its own nickname, avatar, banner and bio in your Discord server, for free. Or go further and run MC Linker as [your own bot](./custom-bot.md).

<img src="/assets/profilecustomization.png" alt="MC Linker customized as 'Villager Bot' with a villager avatar and banner" width="300">

## Change how MC Linker looks in your server

<CommandInfo discord="Administrator or Manage Server" where="Discord servers" needs="Nothing else, it works before you connect a Minecraft server" />

1. Run `/customize` in your server.
2. Click **Change Server Appearance**.
3. Fill in what you want to change:

| Field | What it changes |
|---|---|
| **Nickname** | The name MC Linker shows in your server (up to 32 characters). |
| **Bio** | The *About Me* text on MC Linker's profile in your server (up to 190 characters). |
| **Avatar** | The profile picture in your server. Upload an image. |
| **Banner** | The profile banner in your server. Upload an image. |

Leaving a field empty resets it to the default.

<BotReply command="/customize" title="Customized Server Appearance">Successfully customized MC Linker's appearance in this server!</BotReply>

These changes only apply to your server. Everywhere else MC Linker keeps its usual look.

::: tip Customization Failed?
The image may be invalid, or you changed things too quickly. Use a PNG, JPG or GIF and wait a minute before trying again.
:::
